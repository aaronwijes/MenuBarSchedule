Menu Bar Schedule shows how much time you have until your next class starts/ends.

<img width="503" height="390" alt="image" src="https://github.com/user-attachments/assets/ae101a4a-2c88-4198-bea7-e652b9d798a2" />

## Current Features
* See how much time is left until your next class/event
* Select between 10+ schedule variants
* See your schedule timetable in detail
* Install schedule updates without updating the entire app
* Check for updates on app startup

## Building From Source
There is a build script at `build.py` that can be used to build the app.
Make sure you have installed all of the modules in `requirements.txt` and have ~100MB of free space.

To test your own schedule packs, make your changes and move the `/schedules` directory to `/Users/USERNAME/Library/Application Support/MenuBarSchedule/schedules`.
